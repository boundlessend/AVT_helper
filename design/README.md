# Макеты интерфейса

Пять направлений для главного окна `AVT_helper`, собранные как статические HTML-макеты
в масштабе окна 1120 x 748. Данные во всех макетах одни и те же и вымышленные:
серия «Ночной рейс», 412 реплик, 9 ролей.

Посмотреть: `python3 -m http.server 8123` из этой папки, дальше `http://localhost:8123/`.

| Файл | Направление | Главный объект окна |
| --- | --- | --- |
| `1-list.html` | Монтажный лист | содержимое файла: таймкод, роль, реплика |
| `2-console.html` | Пульт | роль как канал со шкалой реплик |
| `3-timeline.html` | Таймкод | ось времени, дорожка на роль |
| `4-grid.html` | Ведомость | таблица с именами будущих файлов |
| `5-native.html` | Системный канон | привычная раскладка «Настроек» macOS |

## Что выбрано

В работу взят **1. Монтажный лист**. Роль подсвечена маркером: до разролёвки цвет
назначается автоматически по порядку роли, после разролёвки лист перекрашивается
в цвета голосов, то есть ровно в то, что попадёт в DOCX.

**2. Пульт** сохранён как идея на будущее: роль там первичный объект, а шкала реплик
на канале сразу показывает, кто несёт серию. Годится, если понадобится окно
планирования смен, а не конвертации.

Каждый макет начинается с комментария, в котором записаны тезис направления, палитра,
сценарий и состав первого экрана.
