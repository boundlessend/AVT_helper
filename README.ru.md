`AVT_helper` — нативное macOS-приложение для конвертации субтитров и создания DOCX-таблиц с репликами.

Приложение импортирует `ASS`, `SSA`, `SRT`, `VTT` и `SRP`, экспортирует `ASS`, `SRT`, `VTT` и `DOCX`, а также умеет делать DOCX-разролёвку с цветами выделения Word.

Окно показывает импортированный файл монтажным листом: тайминг, роль, реплика. Каждая роль подсвечена маркером, а после разролёвки лист переходит на цвета назначенных голосов, так что экран совпадает с DOCX.

Кодировка входных файлов (UTF-8, UTF-16, Windows-1251) определяется автоматически. Импорт и экспорт идут в фоне с индикатором прогресса и могут быть прерваны, поэтому окно не зависает на больших файлах.

## Установка

1. Скачайте `AVT_helper.dmg` из последнего релиза.
2. Откройте `AVT_helper.dmg`.
3. Перетащите `AVT_helper.app` в `Applications`.
4. Сборка подписана, но не нотаризована, поэтому первый запуск Gatekeeper блокирует. Откройте её один раз так: **правый клик** (или Control-клик) по программе в `Applications`, пункт **Открыть**, затем подтвердите в диалоге. Если macOS всё равно отказывает, зайдите в **Системные настройки → Конфиденциальность и безопасность**, прокрутите вниз и нажмите **Всё равно открыть**.

Дальше macOS запоминает решение и открывает программу обычным способом.

Если система называет программу повреждённой, дело в карантинном флаге. Снимите его один раз в Терминале, без `sudo`: после копирования файл принадлежит вам.

```bash
xattr -dr com.apple.quarantine "/Applications/AVT_helper.app"
```

## Использование

> Язык интерфейса следует за системой. Другой выбирается в `Настройках` (`Cmd+,`) -> `Язык приложения`; меню и системные панели перейдут на него после перезапуска, который программа предложит сама.

1. Нажмите `Открыть субтитры` (`Cmd+O`), перетащите файлы на лист в центре окна или откройте их из Finder. Недавние лежат в `Файл` -> `Открыть недавние`.
2. Выберите папку выгрузки в левом рельсе. Она запоминается между запусками.
3. Отметьте один или несколько форматов: `ASS`, `SRT`, `VTT` или `DOCX`.
4. Отметьте нужные роли в списке справа, если выгружаете отдельные файлы SRT по ролям.
5. Нажмите `Начать` (`Cmd+Return`, он же в меню `Обработка`). Долгую операцию можно прервать кнопкой `Отменить`.
6. Чтобы создать DOCX-разролёвку, загрузите файл с ролями и нажмите `Сделать разролёвку` (`Cmd+Shift+R`).

Существующие файлы не перезаписываются: к имени нового файла добавляется номер.

### Очередь файлов

Бросьте или откройте несколько файлов сразу, и они встанут в очередь в левом рельсе. `Начать` прогоняет всю очередь одними настройками экспорта и помечает каждый файл его исходом. Монтажный лист показывает выбранный файл; отметки ролей относятся к нему, у остальных файлов берутся все их роли. Разролёвка делается по одному файлу: у каждой серии свой состав ролей.

### Что сохраняет экспорт ASS

Блоки `[Script Info]` и `[V4+ Styles]` исходного файла переносятся, поэтому имена стилей разрешаются, а разрешение кадра остаётся прежним. Теги оформления внутри реплики (`{\i1}` и подобные) снимаются при импорте: окно показывает монтажный лист, а не типографику. Строки со стилем, не объявленным в файле, получают `Default` вместо ссылки на несуществующий стиль.

## DOCX

DOCX-файлы содержат название файла, список найденных ролей, таблицу таймингов/ролей/реплик и статистику по ролям. DOCX-разролёвка также показывает назначенные голоса над таблицей и выделяет назначенные роли выбранными цветами Word.
